The PrimeFaces 17 themes support light and dark mode, selected by the CSS color-scheme of the page. LightSwitch sets the color-scheme to light or dark, automatically based on the OS settings or with its JavaScript API, and remembers the selection on the server. Put it in your template like:

<html style="color-scheme: \#{empty userBean.colorScheme ? 'light dark' : userBean.colorScheme}">
...
<pe:lightSwitch selected="\#{userBean.colorScheme}"/>

userBean should be a session scoped bean with a String type colorScheme property (with both getter and setter). Its value is light or dark. Rendering it on the html element avoids a flash of the other mode on page load.

A different theme per mode

Optionally, the light and dark attributes name a theme to switch to as well, e.g. <pe:lightSwitch selected="\#{userBean.colorScheme}" light="aura" dark="metal"/>. Then also bind the theme in your web.xml:

<context-param>
    <param-name>primefaces.THEME</param-name>
    <param-value>\#{userBean.theme}</param-value>
</context-param>

Migration from PrimeFaces Extensions 16: selected holds the color scheme (light / dark) instead of a theme name, the light / dark attributes have no default anymore (formerly saga-blue / arya-blue), and the switch event carries the color scheme.
