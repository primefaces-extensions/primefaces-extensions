Extensions for  pe: PrimeFaces

PrimeFaces Extensions is a lightweight, open source component library built on top of PrimeFaces: components missing in other Jakarta Faces libraries, plus useful behaviors, converters and functions.

Quick Start

So simple to use

Add the Maven dependency next to PrimeFaces, declare the namespace, drop a component tag. The components use the PrimeFaces themes, no extra setup needed.

Read the Docs
pom.xml page.xhtml 
<dependency>
    <groupId>org.primefaces</groupId>
    <artifactId>primefaces</artifactId>
    <version>#{app.primeFacesVersion}</version>
</dependency>

<dependency>
    <groupId>org.primefaces.extensions</groupId>
    <artifactId>primefaces-extensions</artifactId>
    <version>#{app.extensionsVersion}</version>
</dependency>
<html xmlns="http://www.w3.org/1999/xhtml"
      xmlns:h="jakarta.faces.html"
      xmlns:p="primefaces"
      xmlns:pe="http://primefaces.org/ui/extensions">
<h:head>
    <title>My App</title>
</h:head>
<h:body>
    <h:form>
        <p:inputText value="\#{bean.amount}">
            <pe:calculator />
        </p:inputText>
        <pe:qrCode renderMethod="canvas" text="\#{bean.url}" />
    </h:form>
</h:body>
</html>

Theming

Looks like PrimeFaces

The components follow the PrimeFaces design tokens: the presets Aura, Lara, Nora, Metal and Glass, each in a light and a dark color scheme. Change the primary color, density or any token without a build step. Try it with the palette button at the right edge.

  • All PrimeFaces presets supported
  • Light and dark variants for every preset
  • Theme configurator with live token editing
  • Right-to-left and localized components
