Session Session provides client-side callbacks to inform users about session timeout events within your web application.
Basic usage

The basic configuration for client-side session management. A warning dialog is shown reactionPeriod (60 s) before the session expires, followed by an expiry dialog. The showcase session timeout is 60 minutes, so the dialogs only appear after a long idle time. After expiry, reload the page to continue.
