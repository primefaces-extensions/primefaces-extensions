CommandPalette CommandPalette is a filterable grouped context menu: a searchable popup with categorized options, triggered by right-click on a target element. Based on stak-grouplist by newk5.

Basic usage with right-click trigger and grouped items.

Using the select AJAX event to handle item selection on the server side.

Hotkey Trigger

Trigger the CommandPalette via a keyboard shortcut using p:hotkey (Ctrl+Shift+K). The palette also remains available via right-click on the target element.

Right-click or press Ctrl+Shift+K to open the CommandPalette
