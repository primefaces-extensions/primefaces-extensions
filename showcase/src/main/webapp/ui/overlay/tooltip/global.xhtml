Tooltip Global In global mode a single tooltip uses the title values of all (or selected) components on the page and survives Ajax updates. Based on qTip2 - Pretty powerful tooltips.
Global limited tooltips

Global tooltips can be limited to specific components with the for attribute. Here tooltips only appear for inputs that failed validation, a nice replacement for regular error messages. Submit the empty form.

Global tooltips

A global tooltip without for applies to every element with a title on the page, including the showcase shell. It is therefore shown on its own standalone page.
