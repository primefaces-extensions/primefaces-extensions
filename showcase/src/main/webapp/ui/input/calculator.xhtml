Calculator Calculator is a highly configurable component that attaches a popup calculator to an input field. Features include a Scientific or Standard button layout, localization and RTL support, and it works with any input field including InputNumber. Based on jQuery Calculator by Keith Wood.
Basic Usage

Attach a calculator to h:inputText, p:inputText and p:inputNumber. It can be embedded in the input component or configured externally with for.

Localization and RTL

Calculator can be localized. Select a language to change the text and tooltips. RTL (right to left) is supported as well.

Advanced Usage, events and callbacks

Control the calculator from JavaScript, use the onopen, onclose and onbutton callbacks and handle the server side open, close and button events with p:ajax.
