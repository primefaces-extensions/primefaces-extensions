CodeScanner CodeScanner is a multi-format 1D/2D barcode image scanner that scans bar and QR codes using a client side video input device. Based on ZXing for JS.

Requirements

Important: parts of the JavaScript of this component require https (or localhost). If the component is not working for you on a remote server, try running the showcase on localhost.
Basic Usage

Scan a bar or QR code with your camera. The scanned text is written to the input field (for) and the codeScanned event is sent to the server.
