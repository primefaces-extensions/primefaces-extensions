ClockPicker ClockPicker is a highly configurable component to integrate time inputs (hours / minutes) in a convenient way. Based on clockpicker by weareoutman.

The align attribute controls which edge of the popover aligns with the input. For placement="top" or "bottom" use left (default), center or right. For placement="left" or "right" use top or bottom.
