CreditCard Credit Card will take any credit card form and make it the best part of the checkout process (without you changing anything). Everything is created with pure CSS, HTML and JavaScript, no images required. Based on Card.

Field names

Important: Card finds the form fields by their HTML name attribute, which must be number, name, cvc and expiry. JSF prefixes the name of a p:inputText with the form id, so the example uses plain HTML inputs. Alternatively disable the form id prefix and use these component ids, see Stack Overflow.
Basic Usage

Map the input fields to the fields you probably already have. The card follows what you type; the expiry month picker feeds the hidden expiry field.
