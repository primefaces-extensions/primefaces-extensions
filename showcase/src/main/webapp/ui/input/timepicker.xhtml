TimePicker TimePicker is a highly configurable component to integrate time inputs (hours / minutes) in a convenient way. A typical area of application is working time registration, expense and travel accounts. See the Internationalisation page for how to localize the component in multi-language applications.
Basic usage and three modes

Time picker has three modes: inline, popup and spinner. The spinner is the most convenient because it increments / decrements hours and minutes, but it is not compatible with onHourShow / onMinuteShow. The customized picker sets the time separator, start / end hours and minutes, the minute interval, buttons and more.

Advanced usage, events and callbacks

AJAX events timeSelect, beforeShow and close, hours-only and minutes-only pickers, restricted time via onHourShow / onMinuteShow callbacks, and a custom locale (try "Change Locale").

Setting min. / max. time

Time picker supports minimum and maximum hours and minutes. They can also be set from JavaScript with the widget methods setMinTime(hour, minute) and setMaxTime(hour, minute).

Time range
