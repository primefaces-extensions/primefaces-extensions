Converters PrimeFaces Extensions has built-in converters: pe:convertJson and pe:convertGson convert values to and from JSON, pe:convertLocale converts a locale string to a java.util.Locale and pe:sanitizer sanitizes input with an OWASP HTML policy.

JSON data types

pe:convertJson has one optional attribute type which specifies the data type of the value object. Any primitive type, array, non generic or generic type is supported. The data type is sometimes required to convert a value to or from its JSON representation. All data types should be fully qualified. Examples:

  • boolean
  • int
  • long[]
  • java.lang.String
  • java.util.Date
  • java.util.Collection<java.lang.Integer>
  • java.util.Map<java.lang.String, com.prime.FooPair<java.lang.Integer, java.util.Date>>
  • com.prime.FooNonGenericClass
  • com.prime.FooGenericClass<java.lang.String, java.lang.Integer>
  • com.prime.FooGenericClass<int[], com.prime.FooGenericClass<com.prime.FooNonGenericClass, java.lang.Boolean>>

The tag documentation shows convertJson, convertLocale and sanitizer; convertGson is the Gson based alternative to convertJson and sanitizerLenient is the lenient variant of sanitizer.
JsonConverter with pe:remoteCommand

JsonConverter applied to a RemoteCommand: attach pe:convertJson to pe:assignableParam. The JavaScript objects are sent as JSON and converted to a Circle bean.
JsonConverter with f:viewParam and URL parameters

JsonConverter sets a value from a URL request parameter into a bean with f:viewParam and pe:convertJson. Use RequestParameterBuilder to build URL parameters in JSON representation. This pre-initializes forms with default values passed in the URL on the initial page load (GET request). The demo covers primitives, arrays, simple types, java.util.Date, parametrized collections and maps, and generic and non generic classes. Click "Open Link" there to see the URL parameters set into the bean. URLs longer than 2083 characters may not work in old browsers.

SanitizingConverter

The SanitizingConverter (pe:sanitizer) sanitizes any input using an OWASP Java HTML Sanitizer PolicyFactory. It is useful for cleansing input that is displayed in an h:outputText with escape="false".
