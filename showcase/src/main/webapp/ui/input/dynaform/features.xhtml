DynaForm Features DynaForm supports facets, the autoSubmit feature, an extended view area (grid) and a client-side widget API. The examples show an advanced search form and two switchable forms rendered by the same XHTML.
Advanced features

An advanced dynamic form with facets, the autoSubmit feature and an extended view area (grid). The form was already submitted on page load: autoSubmit allows passing form parameters in the URL, building the form on page load and submitting it automatically. The extended grid is closed by default; open it with the client-side API ("Show / hide advanced search"). The open / close state is kept after a postback.
Yet another forms

Dynamic forms with labels above the fields and various elements such as the PrimeFaces divider. Click "Switch model" to switch between the two forms: the XHTML with pe:dynaForm stays the same, only the Java model changes.
