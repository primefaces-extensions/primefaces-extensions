DynaForm Basic DynaForm builds a dynamic form with labels, inputs, selects and any other elements from a model, for forms that are described at runtime (for example in a database or an XML file). It adds an expandable extended view area, open / close state saving, an autoSubmit feature, a client-side widget API and various facets.

Background

Normally a form can be built straightforwardly with h:panelGrid or p:panelGrid if the count of rows / columns and the positions of elements are known. That is not possible if a form is described dynamically at runtime. DynaForm builds such a form from a Java model without limitations.

Supported facets: headerRegular, footerRegular, headerExtended, footerExtended and buttonBar.
Basic usage

Build a simple dynamic form: create a DynaFormModel, add rows with createRegularRow(), add labels with addLabel(...) and controls with addControl(data, type, ...), and link them with label.setForControl(control). The child tag pe:dynaFormControl matches the Java controls by its type attribute (usually one to many). Labels are rendered automatically, no p:outputLabel is needed.

Utilization of nested model

A nested model is like a table contained in a cell, which is useful when a control is a combination of several pe:dynaFormControl. The XHTML stays the same, only the Java model changes: create a second DynaFormModel, fill it as usual and add it with nestedRow.addModel(data, type, ...).
