DynaForm Controls DynaForm gives access to the client ids of its controls and lets you visit all controls with a visit callback, for inter-control communication, clearing inputs and removing rows at runtime.
Utilization of container client Id

The attribute varContainerId names a variable holding the client id prefix within pe:dynaFormControl, which gives the whole client id of a component inside it. That is sometimes required for JavaScript or PrimeFaces.current().ajax().update(...). Every input here has an icon to select a value from a dialog; the value is set into the input after a click on "OK".

Access controls with visit callback and remove rows

ExecutableVisitCallback is the PrimeFaces Extensions implementation of the JSF VisitCallback. It runs any VisitTaskExecutor on all controls within pe:dynaForm, which allows inter-control communication. Here ClearInputsExecutor clears all inputs / selects of one row (see clearInputs in ClearDynaFormController). Rows are removed at runtime with removeRegularRow(...) / removeExtendedRow(...) of the DynaFormModel. Click "Clear inputs" and "Remove" to see it in action.
