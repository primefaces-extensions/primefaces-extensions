Timer Basic Timer fires a JSF listener after a customizable interval. It also provides a JavaScript API to start, pause and stop the timer.
Basic usage

The interval is set via timeout. Set singleRun to false to make it periodic; the listener fires every 5 seconds here.

Direction

Choose the direction of the timer with the forward attribute.

JS Api

The timer can be controlled from JavaScript: start, pause, restart and stop. When stopping, pass true to stop silently and skip the JSF listener.
