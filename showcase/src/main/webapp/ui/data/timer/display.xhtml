Timer Display The value of the Timer can be formatted or hidden. Timer fires a JSF listener after a customizable interval. It also provides a JavaScript API to start, pause and stop the timer.
Interval format

Display the remaining time as seconds (default), percentage, human text, localized, with a custom moment.js pattern, or via a formatFunction. The script below sets moment.js locales globally, which is why this example is on a page without other formatted timers.

Invisible

With visible="false" the timer is rendered but hidden. Use the ontimerstep client callback to update your view, here a Knob that acts like a timer.
