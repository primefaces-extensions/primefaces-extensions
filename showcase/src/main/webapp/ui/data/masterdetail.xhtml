MasterDetail MasterDetail groups contents into levels (sections) and saves page space. Smart and flexible navigation between levels via built-in breadcrumbs or command components gives users a neat and stylish interface.
Basic navigation level by level

Straightforward navigation by means of the pe:selectDetailLevel handler. Context values (any objects) are passed from level to level and available via context variables. The level to go to is set via level or step (default step=1); the breadcrumb text via levelLabel or the label facet.

Wizard-like navigation with forms

Wizard-like navigation with form fields. The header and footer facets render content above and below the levels, shared between all levels, which allows a custom title bar instead of the built-in breadcrumbs.

Master-detail views with CRUD operations

Complex master-detail views with CRUD operations and a server-side flow listener. The SelectLevelEvent passed into the listener and its return value control the level to navigate to: after a successful save of the detail view (level 2) go back to the master view (level 1), otherwise stay.

Overview

Each level in the flow is represented by a pe:masterDetailLevel component. Switching between levels is done by the pe:selectDetailLevel handler and is based on AJAX, so each level is loaded dynamically. pe:selectDetailLevel can be attached to any ajaxified PrimeFaces or non-PrimeFaces component, typically CommandLink, CommandButton, MenuItem, RemoteCommand, HotKey and any component with an attached f:ajax / p:ajax.

This gives flexible control over partial validation and over calling action / actionListener during navigation. The area updated during navigation is set automatically to the pe:masterDetail component; processed and updated areas can be controlled more precisely by process / update. Partial validation can be skipped by process="@none" or immediate="true", and is always skipped for navigation via breadcrumbs. Other features are a server-side listener invoked when a navigation attempt takes place and the header / footer facets.

Attention: reference the pe:masterDetail in the update attribute of command components manually if the page has auto-updating components such as p:growl or p:message with p:autoUpdate.

Known limitation: MasterDetail does not work inside data iteration components extending UIData, e.g. inside a DataTable: navigation will not work there.
