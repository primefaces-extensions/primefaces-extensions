Sheet Basic Sheet fills a need that the PrimeFaces DataTable with in-cell editing does not fill. It handles a large amount of data and edits single cells without submitting the entire sheet. Based on Handsontable by Handsoncode.
Basic Usage

Fixed columns and rows, custom cell styling, sorting, filtering and per-cell validation. Enter "abc" into the Price column, which expects a BigDecimal.

Data Export

Sheet data can be exported with p:dataExporter just like a DataTable. Use the toolbar buttons to export CSV or XML; the exporter respects the current sort and filter state.

Dynamic Columns

Create columns dynamically and render their style and other attributes from backing beans. Also shows how to customize the Handsontable instance with updateSettings and the extender JavaScript.

Features

  • Fast in-cell editing and validation
  • Copy/Paste
  • Range selection including copy/paste and fill
  • Sorting
  • Filtering
  • Fixed columns and rows
  • Resizable columns and rows
  • Movable columns and rows
  • Ajax updates and validation
