Sheet Columns Columns can be moved and validated individually. Sheet is a spreadsheet-like in-cell editing component based on Handsontable by Handsoncode.
Movable Columns

Sheet supports movable columns and rows with sorting and filtering. Drag a column header to reorder; sort and filter elements follow the column, and columns without them (like Icon) can be moved freely.

Validation

Cells and columns can be validated individually as well as marked required: converters, range validators, JavaScript validators (onvalidate) and Faces validators.
