Sheet Events Sheet fires ajax events for cell selection, changes, sorting, filtering and row or column selection. Sheet is a spreadsheet-like in-cell editing component based on Handsontable by Handsoncode.
Ajax Events

Sheet provides the ajax events cellSelect, change, sort, filter, columnSelect and rowSelect. Click a header once to select it, then you may move columns around when the hand icon appears.

Outside Click Deselects

When outsideClickDeselects is false, clicking outside the sheet keeps the current selection.
