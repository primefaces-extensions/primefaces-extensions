TimeAgo Localized TimeAgo texts can be localized with the locale attribute. TimeAgo generates automatically updating fuzzy timestamps (e.g. "4 minutes ago"). Based on jquery-timeago by Ryan McGeary.
Localized

Register the strings of a locale in PrimeFacesExt.locales.TimeAgo and select it with locale. The locale is applied to the whole jquery-timeago plugin, which is why this example is on its own page.
