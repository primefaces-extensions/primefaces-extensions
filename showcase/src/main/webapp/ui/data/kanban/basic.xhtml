Kanban Basic Kanban is a board component for visualizing workflow and managing tasks with drag-and-drop, including touch drag-and-drop on mobile devices. Based on jkanban by Riktar.
Basic Usage

A board with three columns bound to a list of KanbanColumn. Drag items between columns and add new ones with addItemButton; drop and itemAdd fire ajax events.

Custom Data Attributes

Any key-value data added to a KanbanItem via putData(key, value) is rendered as a data-* attribute on the card. Here the extender turns them into badges and CSS attribute selectors color the priority; inspect a card to see the attributes.

Layout Tuning

Control the spacing between boards (gutter), the width of each board (widthBoard) and whether boards use percentage-based widths (responsivePercentage).
