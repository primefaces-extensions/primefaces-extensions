Kanban Interaction Kanban items react to clicks, right-clicks and the client-side widget API. Kanban is a board component for visualizing workflow and managing tasks with drag-and-drop, including touch drag-and-drop on mobile devices. Based on jkanban by Riktar.
Item Interaction

Click an item on the board to view and edit its details in a dialog (the itemClick event).
Right-Click Context Menu

The bindContextMenu attribute and the itemRightClick event open a PrimeFaces context menu on a task with options to edit, view history or delete. The addItemButton of each column adds new tasks.

Right-click on a task and select "Edit Task" to see its details here.

Client API

The widget exposes a client-side API via PF(widgetVar).methodName(): addElement, findElement, findBoard, getParentBoardID, getBoardElements, replaceElement and removeBoard. Try them with the toolbar; click a task to fill the item id.
