OrgChart OrgChart is a simple and direct organization chart component. Anytime you want a tree-like chart, you can turn to OrgChart. Based on orgchart by Xuebin Dong (dabeng).
Basic Usage

A tree-like chart with dragging, panning, zooming and export to PDF.

Color Coded

Use CSS classes to color-code nodes by department, role or any other criteria. Set the className property on each node to apply custom styling.

  • ■ gold-level - Executive Team
  • ■ green-level - Middle Management
  • ■ blue-level - Tech Staff
  • ■ red-level - Sales Staff
  • ■ purple-level - Support Staff
Variable Width Nodes

Nodes can have different widths to accommodate varying content lengths. Use the className property and custom CSS on .orgchart .your-class .title and .content to set the widths (default 130px): wide-node 240px, standard-node 160px, narrow-node 100px.

Filter Node

Client-side node filtering through the widget API: the quick action buttons call filterNodes and clearFilter, the filter input of the chart works as well.

Compact Mode

Nodes marked compact=true render their children in a grid inside the parent node, which helps when many children exist. Bo Miao is compact and includes a nested compact node (Si Xuan); use the green corner controls to switch between compact and loose layouts.

Icons

OrgChart uses Font Awesome for its icons (for example parentNodeSymbol="fa-folder-open"). As Font Awesome is no longer included in PrimeFaces, include Font Awesome in the pages that use OrgChart. The showcase already does.
