SunEditor SunEditor is a lightweight, flexible, customizable WYSIWYG text editor for your web applications. Based on SunEditor by Yi JiHong. With the default theme auto the editor follows the color scheme of the page.
Basic Usage

A WYSIWYG editor with a configurable toolbar. Change the mode, theme, locale and direction with AJAX; the paste, copy, cut, drop and save events are sent to the server. The theme Auto picks the light or dark theme from the page.
