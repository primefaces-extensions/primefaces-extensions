CodeMirror CodeMirror is a JavaScript library that can be used to create a relatively pleasant editor interface for code-like content: computer programs, HTML markup and similar. If a mode has been written for the language you are editing, the code is coloured and the editor helps with indentation. Based on CodeMirror.js by Marijn Haverbeke.

Basic Usage

CodeMirror is fully updateable via AJAX as you can see with the select menus below: change the theme, the mode or the keymap.

Code Completion

Set completeMethod to a server-side method that returns suggestions. Press Ctrl-Space in the editor to open the proposals; the mode can be changed with AJAX.

JS Code Completion

The JavaScript hint add-on of CodeMirror can be bound with extraKeys. Press Ctrl-Space in the editor to complete JavaScript code on the client.
