MarkdownEditor MarkdownEditor is a text area replacement for writing beautiful and understandable Markdown. It allows users who may be less experienced with Markdown to use familiar toolbar buttons and shortcuts, and renders the syntax while editing. Based on Easy MDE by Sparksuite, Inc, Jeroen Akkerman.
Basic Usage

A lightweight, flexible and customizable Markdown editor with a configurable toolbar, side-by-side mode and RTL support. The paste, copy and cut events are sent to the server.
