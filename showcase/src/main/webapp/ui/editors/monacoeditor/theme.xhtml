MonacoEditor Theme MonacoEditor accepts custom style and color themes defined with the Java API or the client-side API of Monaco.
Custom Theme

Define a custom style and color theme with the customThemes attribute, then enable it with the theme option of editorOptions. See the example on the Monaco editor homepage. For more fine-grained control use the client-side API via the extender attribute. The custom theme is selected explicitly, so it does not follow the color scheme of the page.
