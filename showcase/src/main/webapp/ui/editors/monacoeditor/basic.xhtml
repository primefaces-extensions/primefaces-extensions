MonacoEditor Basic MonacoEditor is the code editor which powers VS Code, as a JSF component: inline (pe:monacoEditor) or in an iframe (pe:monacoEditorFramed).

Component variants

The Monaco Editor is the code editor which powers VS Code. It offers IntelliSense and validation for JavaScript/TypeScript, CSS/LESS/SCSS and JSON, syntax highlighting for many more languages, and comes with localization for a few major languages. This component is a wrapper that allows Monaco Editor to be used as a JSF component and comes in four varieties:

  • pe:monacoEditor renders the editor inline in the page. This is usually more efficient and the preferred way when you do not need different editors with a different global configuration.
  • pe:monacoEditorFramed renders the editor in an iframe for improved encapsulation. Part of the Monaco configuration is window global, such as the loaded TypeScript declaration files; use the framed variant for multiple editors with a completely different setup.
  • pe:monacoDiffEditor renders a diff editor for comparing two files inline in the page.
  • pe:monacoDiffEditorFramed renders a diff editor in an iframe.

All variants share almost the same API. The diff editor has additional properties for the settings of the original (left) editor. The framed variant is controlled with postMessage and its client-side API is therefore asynchronous (Promises). The client-side API is fully typed, see primefaces-monaco-global.d.ts and primefaces-monaco-module.d.ts. See also the official client-side API and the Monaco Editor repository (MIT License) by Microsoft.

Keep in mind that Monaco is not supported in mobile browsers or mobile web frameworks, and that the Promise API is required (every current browser supports it).

The editors follow the color scheme of the page: monacoColorScheme.js sets the theme vs-dark in dark mode while the configured theme is the default vs.

Basic Usage

MonacoEditor is fully updateable via AJAX as you can see with the select options below. It also keeps its scroll position during an AJAX update. Switch between the inline and the iframe variant of the editor.

Events

The widget forwards several events of the Monaco API: blur, change, focus, initialized, keydown, keyup, mousedown, mousemove, mouseup and paste. Attach a server-side listener with p:ajax or a client-side callback with the on<event> attributes. Here every event shows a growl message in the onstart callback of the behavior and cancels the request by returning false; avoid server-side listeners for frequent events such as mousemove.
