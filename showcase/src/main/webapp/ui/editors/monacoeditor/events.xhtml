MonacoEditor Events MonacoEditor forwards the events of the Monaco API as AJAX behavior events and client-side callbacks.
Events

The widget forwards several events of the Monaco API: blur, change, focus, initialized, keydown, keyup, mousedown, mousemove, mouseup and paste. Attach a server-side listener with p:ajax or a client-side callback with the on<event> attributes. Here every event shows a growl message in the onstart callback of the behavior and cancels the request by returning false; avoid server-side listeners for frequent events such as mousemove.
