MonacoEditor Diff MonacoDiffEditor compares two files side by side or inline: pe:monacoDiffEditor renders it in the page, pe:monacoDiffEditorFramed in an iframe.

Diff editor

pe:monacoDiffEditor and pe:monacoDiffEditorFramed compare two files. The value is a MonacoDiffEditorModel with the original (left) and the modified (right) text; the original editor has its own originalRequired, originalDisabled and originalReadonly attributes. See the Basic page for the overview of all component variants. The editors follow the color scheme of the page: monacoColorScheme.js sets the theme vs-dark in dark mode while the configured theme is the default vs.
Basic Usage (diff editor)

The diff editor is supported as well. It is fully updateable via AJAX as you can see with the select options below and keeps its scroll position during an AJAX update. Switch between the inline and the iframe variant, side-by-side or inline diff.
