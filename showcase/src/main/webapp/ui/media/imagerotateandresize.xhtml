ImageRotateAndResize The ImageRotateAndResize widget rotates or resizes images and provides events to catch the new image values on the server side. It uses the HTML5 Canvas.
Basic Usage

The widget provides client side methods which can be called with JavaScript: rotateLeft(degree), rotateRight(degree), resize(width,height), scale(scaleFactor) and restoreDefaults(). The events rotate and resize are sent to the server.
