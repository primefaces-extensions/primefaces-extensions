ImageAreaSelect ImageAreaSelect is a widget for selecting a rectangular area of an image. It allows web developers to easily implement image cropping functionality, as well as other user interface features, such as photo notes (like those on Flickr).
Basic Selection

The basic configuration enables persistent and resizable selection of an area. The selectEnd event reports the selection.

Customized Selection

The widget is highly configurable. Here the selection is not persistent, hides automatically after the selection is done, has no handles and can neither be moved nor resized.

ImageAreaSelect with ImageRotateAndResize

ImageAreaSelect and ImageRotateAndResize can be combined. The image is completely redrawn after a resize or rotate action, so the ImageAreaSelect stops working until its reload() is called. Without a server side listener for the event, p:callback reloads the widget; here the resize event is caught with p:callback.
