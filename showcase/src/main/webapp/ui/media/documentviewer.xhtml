Document Viewer DocumentViewer is a JSF wrapper of the PDF.js project of the Mozilla Foundation, a general-purpose, web standards-based platform for parsing and rendering PDFs. It displays PDF documents inline without a browser plugin and supports localized languages (supported browsers).
Basic usage

DocumentViewer can be used in three modes: a url, a JSF resource (library and name) or a PrimeFaces StreamedContent (value).

Advanced Usage

It is also possible to set the locale and the starting page of the DocumentViewer.
