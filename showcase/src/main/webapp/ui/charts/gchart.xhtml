GChart GChart is a JSF wrapper of the Google Charts API, the chart library used by Google Analytics and other Google services. It also provides an organizational chart and a geo chart.

Important

Due to the Google Charts Terms of Service it is not possible to download the library to a server: the API is loaded from the servers of Google, so the client must be connected to the internet for the component to work.
Basic usage

The component needs a GChartModel, created with a GChartModelBuilder. The select AJAX event contains a JSONArray with the selected rows.

Multiple Series

A chart can have multiple series: choose the right GChartType (COLUMN here) and fill more columns.

Organizational Chart

Google Charts is versatile: here it displays an organizational chart. A TreeNode can generate the GChartModel for this kind of chart.

Geo Chart

A geo chart shows data about countries. Rows are added with simple strings or with java.util.Locale.
