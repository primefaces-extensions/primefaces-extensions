OSMap Markers OSMap shows the markers of a map model and fires events when a marker is selected or dragged. Based on Leaflet by Volodymyr Agafonkin and OpenStreetMap.
Marker usage

Markers are added to the model of the map.

Marker Selection

The overlaySelect event fires when a marker is clicked: click a marker.

Draggable Marker

Markers can be draggable: the markerDrag event fires when a marker is dropped. Drag a marker.
