Keynote Markdown Slide content can be written in Markdown instead of HTML. Presentations are made with reveal.js.
Markdown

Add markdown="true" to a pe:keynoteItem and wrap the contents in it. Slides are separated by three dashes by default; separator and separatorVertical set a regular expression instead. Markdown is sensitive to indentation (do not mix tabs and spaces) and line breaks (avoid consecutive breaks), so the content starts at the first column.
