Keynote Basic Keynote is an HTML presentation component to create fully-featured and beautiful presentations. Presentations made with reveal.js are built on open web technologies.
Basic Usage

Slides are defined by pe:keynoteItem; nested items create vertical slides, and visibility="uncounted" or visibility="hidden" control how a slide is counted (slideNumber="c/t"). Use the arrow keys or the controls to navigate.
