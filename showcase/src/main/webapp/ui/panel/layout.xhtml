Layout Layout creates a border layout that has an auto-sizing 'center pane' surrounded by up to four closable and resizable 'border panes' (north, south, east and west). Layouts can be nested, used for an entire page (full page layout) or for a region of the page (element layout), and have client-side and server-side state management.
Element layout and server-side state management

Setting fullPage="false" creates an element layout. Two element layouts with server-side state management are shown below: resize, open or close panes and switch between the layouts. Both are described by LayoutOptions bound to the options attribute; options can also be set as attributes of pe:layoutPane (the Java model takes precedence).

Full page layout, events and client-side state management

A full page layout with nested panes, the AJAX events open, close and resize and client-side state management (stateCookie="true"). The buttons in the north pane call the widget methods sizePane(), toggle(), close() and open(); nested panes are addressed with _, e.g. sizePane('center_north', 300). The "center" pane itself can not be manipulated. Source: fullPage.xhtml below.

Layout created by options as tag attributes

The layout is created by options defined as attributes of pe:layoutPane, without a LayoutOptions model. Default tooltips (resize, open, close, slide) are redefined on pe:layout and per pane. Layout panes support a limited set of options compared to LayoutOptions. Source: fullPageAttr.xhtml below.

Custom content between layout panes

Custom content can be placed between layout panes by putting nested panes in a div with the class ui-layout-content (shown here, the nested panes come from an included page), by the option containerSelector of the child options, or in the header facet of a pane, which stays fixed while the pane content scrolls (shown here with messages). Call the widget method sizeContent(pane) when custom content changes its height. Source: customContent.xhtml and customContentNested.xhtml below.

IFrame acting as layout pane (tips to objects within panes)

An iframe can be a direct child of a layout pane. Set maskContents="true" on the pane to avoid resizing issues with iframes (maskObjects="true" for objects such as maps), and consider maskPanesEarly="true" on pe:layout. The style class .ui-layout-mask is made visible in this example. Source: iframe.xhtml below.

Layout Options

The layout is described by a model which binds all layout options together: the class LayoutOptions. This way all options of the underlying jQuery layout plugin are available, see the overview of layout options, the layout examples site and the changelog.

Alternatively the mostly used options can be set as tag attributes of pe:layoutPane; no LayoutOptions is needed then, but the possibilities are limited.

The options attribute points to an instance of LayoutOptions or to a JSON string of serialized LayoutOptions. LayoutOptions are always serialized to JSON for the widget; when the layout is built once in an application scoped bean, use toJson() to serialize the options once and pass the string.
