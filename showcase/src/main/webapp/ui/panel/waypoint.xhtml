Waypoint Waypoint makes it easy to execute custom logic whenever you scroll to an element. Waypoints are a solid base for modern UI patterns that depend on the scroll position of a page; vertical and horizontal scrolling are supported. Based on Waypoints JS by Caleb Troughton.

Events

Waypoint can be used either with p:callback or p:ajax. There is only one event, reached: it is fired when the user scrolls past the element. In the callback function you can access the scrolling direction (down, up, right, left) and the current waypoint element as a DOM object.

Infinite scrolling 1

Infinite scrolling with p:remoteCommand and the offset as a function, which defines a waypoint when the bottom of the element is in view; it is recalculated automatically when the window is resized. The waypoint is used with p:callback, which checks the scrolling direction and calls the widget methods disable() and enable(): disable() temporarily stops the callback from firing but leaves the event bound, and enable() re-enables it. The demo needs the whole page as scroll context and opens in a new window.

Infinite scrolling 2

Lazy loading of images: the waypoint is bound to all images with a data-src attribute and an offset of '100%'. When an image scrolls into view its source is set, it is faded in and its waypoint is destroyed. The demo needs the whole page as scroll context and opens in a new window.

Sticky Elements

A menubar that sticks to the top of the window and a "Back to top" button that appears after scrolling past the page, both driven by waypoints and p:callback. The demo needs the whole page as scroll context and opens in a new window.

Dial Controls

Waypoints within scrollable non-window elements: the forContext attribute names the scrolling elements (the dials), and the waypoint is used with p:callback. Scroll the dials to change the font size, width and background color of the text below them.

Scroll Analytics

Waypoints track user engagement and ad views. The articles scroll inside their own box, which is the scroll context (forContext), and the waypoints are used with p:ajax and p:callback. The offset 'bottom-in-view' is an alias for the function offset of the infinite scrolling demo. Scroll down: each ad turns red when it comes into view and the server is informed; a message pops up when you reach the end of the articles.
