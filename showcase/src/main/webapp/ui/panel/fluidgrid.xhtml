FluidGrid FluidGrid is a cascading grid layout component. It places elements in the optimal position based on the available vertical space, like a mason fitting stones in a wall, and is responsive: the grid reflows as the window size changes. Based on the Masonry JavaScript library.
Static items

Static items are defined by pe:fluidGridItem placed multiple times below pe:fluidGrid. Items can have different widths and heights set by style classes. The container has the style class pe-fluidgrid and each item pe-fluidgrid-item. The attributes hGutter and vGutter set the horizontal and vertical space between items. Resize the browser window to test the fluid grid.

Dynamic items

Dynamic items are put in a collection of FluidGridItem instances; each holds a data object and an optional type that matches the type attribute of pe:fluidGridItem. The items are exposed via value and var. hasImages="true" re-layouts the grid after all images have been loaded, so items do not overlap. The event layoutComplete is fired after the layout and all transitions have completed.

Stamped elements within layout

Stamped elements are special layout elements that are not laid out by the grid; items are placed below them. They are set by the stamp attribute, which can be any PrimeFaces search expression. The widget methods stamp() and unstamp() toggle a stamped element and layout() triggers the layout. Inside a layout pane, set resizeBound="false" to deactivate re-layouting on browser resize.

Dynamic form

A responsive dynamic grid with input fields, similar to DynaForm but not a fixed table: resize the browser window. Place the labels above the input fields for a consistent alignment. The type of pe:fluidGridItem must match the type property of FluidGridItem.

Dynamic labels

Dynamic items whose label attribute on input components is bound to the data model via var. Change Items replaces the grid's items to verify that labels are preserved across dynamic updates. Click Submit with empty required fields: each validation message shows its own component's label.
