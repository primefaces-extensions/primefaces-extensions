Clipboard Clipboard copies or cuts text to the OS clipboard. It shouldn't be hard and it shouldn't require dozens of steps to configure or hundreds of KBs to load, and it doesn't depend on Flash or any bloated framework. Based on Clipboard.js by Zeno Rocha.
Basic Usage

A pe:clipboard can have a fixed text or point to a text component with target. The success and error events are sent to the server. Clipboard can be used in menu options too: right click the page background to show the context menu.
