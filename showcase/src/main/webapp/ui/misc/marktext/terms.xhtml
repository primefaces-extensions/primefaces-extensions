MarkText Search Terms MarkText highlights search terms within specified containers using mark.js by Julien Royer. These examples widen a search term with wildcards, synonyms and diacritics.
Wildcard Search

The wildcards attribute: ? matches one character, * any number of characters.

#{markTextWildcardController.processedText}
Synonyms

The synonyms map highlights synonymous terms in both directions: searching for "one" also highlights "1", and vice versa.

#{synonymsMarkTextController.processedText}
Diacritics

With diacritics="true" characters with and without diacritics match each other, e.g. "e" matches "é".

#{diacriticsMarkTextController.processedText}
