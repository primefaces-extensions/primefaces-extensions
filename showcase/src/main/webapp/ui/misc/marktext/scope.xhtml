MarkText Scope MarkText highlights search terms within specified containers using mark.js by Julien Royer. These examples control where matches are searched: across elements, outside excluded elements and inside iframes.
Across Elements

acrossElements highlights text that spans several HTML elements. This matters when separateWordSearch="false" (exact phrases): a phrase split by tags like <strong> or <em> would otherwise not be matched. Use the checkbox to compare.

This example demonstrates how acrossElements="true" works. By default, separateWordSearch is true, which means "PrimeFaces Extensions" would be found as two separate words. However, in this example, we have set separateWordSearch="false" to search for the exact phrase.

Try searching for "PrimeFaces Extensions". Below, it is rendered as <strong>PrimeFaces</strong> <em>Extensions</em>. Without acrossElements="true", this would not be found as an exact phrase because it is split across two HTML nodes.

Iframes

With iframes="true" MarkText also searches same-origin iframe documents. iframesTimeout controls how long the search waits for frame content before continuing.

This example searches both the parent document and a same-origin iframe. Enable iframes to include embedded frame content in the highlight result.
