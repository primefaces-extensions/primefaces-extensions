MarkText Matching MarkText highlights search terms within specified containers using mark.js by Julien Royer. These examples compare the options that control how a search term matches the text.
Case Sensitivity

With caseSensitive="true" the search is case-sensitive; with false it is case-insensitive.

Separate Word Search

With separateWordSearch="true" each word is searched separately; with false the exact phrase is searched.

Accuracy Levels

accuracy="partially" matches if the search term is contained in the text, exactly only if the text equals the search term, complementarily if the search term contains the text.
