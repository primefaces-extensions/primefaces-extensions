Speedtest Speedtest tests the network speed of your server. It captures download, upload, ping and jitter speed and provides the results in an Ajax callback.
Basic Usage

Start the test with the start() method of the widget. The speed results are sent to the server.
Dummy load file

For testing the download speed you need an uncompressable payload file deployed on your server with a size of 1MB, 2MB, 5MB or 10MB. We recommend using a 5MB file. It can be generated here.
