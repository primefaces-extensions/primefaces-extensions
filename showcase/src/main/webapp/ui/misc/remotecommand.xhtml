RemoteCommand RemoteCommand executes backing bean methods and does a partial update, triggered by custom client side script. It can pass parameters with pe:assignableParam (assigned to bean properties) or pe:methodParam (arguments of a bean method).
Basic Usage

A certain part of a page can be lazily loaded on demand.

Using AssignableParam

Assign JavaScript parameters to a property in a bean with pe:remoteCommand and pe:assignableParam. AssignableParam specifies a name of the parameter and an EL expression for the corresponding setter the parameter is applied to (assignTo). A converter can be attached as a child or with the converter attribute.
Using MethodParam

Call a remote Java method with any parameters from JavaScript with pe:remoteCommand, pe:methodParam and pe:methodSignature. MethodParam specifies the name of a parameter and MethodSignature a comma separated list of fully qualified class names, in the same order as the passed parameters.
