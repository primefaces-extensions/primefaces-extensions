Localized Localized includes large content blocks based on the view Locale or a provided Locale, with fallbacks to default content. It is not recommended for small messages such as labels or headers: use resource bundles there.

Content files

Files should be put in the WEB-INF/pfe-localized folder. Files used in this demo can be found in our GitHub repo.

Files should be named {name}, {name}_{language} or {name}_{language}_{country}. Language and country should match those in the set view locale or the provided locale. See also the Locale documentation.

Basic Usage

These examples use the locale attribute. Normally you want to rely on the Locale set in the view.

Markdown and EL

Markdown requires you to include org.commonmark:commonmark in your project.

Inline

Not recommended, as it is hard to add languages to an application, but useful for a small set of languages. Facets also allow you to use components.
